# SpecDD project specific overrides

## Project rules

- Use Astro static output, TypeScript where application code benefits from types, and plain CSS.
- Keep the site usable without paid services, secrets, or server-side infrastructure.
- Preserve Spanish content, semantic HTML landmarks, keyboard access, visible focus, and reduced-motion support.
- Never add restaurant photos from third-party sites unless the source date and reuse permission are established.
- Do not invent restaurant details; confirm uncertain hours and menu content with the owner.
- Use English Conventional Commit messages.
- Run `npm run build` to verify production output when implementation changes affect the site.
- Use `npm run dev` to preview locally at http://localhost:4321.
